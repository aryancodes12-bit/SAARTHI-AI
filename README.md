## 🌟 What is SaarthiAI?

**SaarthiAI** is a premium, high-fidelity AI insurance advisory platform designed to deliver personalized, event-driven protection guidance. It's not just an insurance tool; it's a digital saarthi (companion) that understands your life journey and ensures you are protected at every milestone.

Built for the Indian market, it combines **cutting-edge AI** with **rigorous privacy standards** (DPDP 2023) to deliver recommendations that are ethical, transparent, and context-aware.

---

## 🧠 Powered By — The Tech Stack

- **⚡ Core Platform**: React 19 + Vite + ESM
- **🎨 Design System**: TailwindCSS + Framer Motion (Modern Premium Aesthetics)
- **🔐 Backend & Auth**: Firebase (Authentication, Firestore, Storage)
- **🤖 Intelligence Layer**: Gemini AI / Custom AI Recommendation Engine
- **🧬 Event Detection**: Heuristic & LLM-based Life Event Detection
- **🛡 Trust Engine**: PII Masking, Bias Monitoring, DPDP 2023 Compliance Layer
- **📊 Interactive Data**: Recharts for Financial & Risk Visualization
- **🎙 Multi-modal**: Voice Call Ready (Vapi-AI integrated)

## 🔐 Privacy & Compliance (DPDP 2023)

SaarthiAI is built on a **Privacy-First Architecture**:

1.  **PII Masking**: Sensitive data is masked locally before being sent to any AI engine.
2.  **Consent Tracking**: Every data point is tied to an explicit purpose and user consent.
3.  **Bias Monitoring**: Responses are audited for demographic or socioeconomic bias.
4.  **Audit Logs**: Clean tracking of data usage for regulatory compliance.

```bash

```

## 🚀 Getting Started

### 1️⃣ Installation
```bash
npm install
```

### 2️⃣ Environment Setup
Create a `.env.local` file with your Firebase and AI credentials:
```env
VITE_FIREBASE_API_KEY=...
VITE_GEMINI_API_KEY=...
```

### 3️⃣ Development
```bash
npm run dev
```
